## 2D Parkour

A simple 2D parkour game made using the Unity Game Engine.

## How It Works

This game has two types of scenes: **Level Scenes** and the **Main Menu Scene**.

In this game, there is one dragon that is our main character. There are many obstacles that the player has to pass to win the game. There are also enemies that can hit and hurt the player. There is also a pause menu with three buttons: **Home, Restart, and Resume**. As the level increases, the difficulty also increases.

## Features

* Player jump
* Player can go forward and backward
* Left mouse click to shoot fireballs
* Win screen
* Pause screen
* Fireball sound
* Background sound

## Controls

* **Space** to jump
* **Left mouse click** to shoot fireballs
* **D** to move forward
* **A** to move backward
